Summary:
Add music kits and improve held-case rendering for v1.1.0

Description:
- Add 101 music-kit definitions with support for 1,563 streaming tracks through optional resource packs.
- Add a CS2-style listening GUI with artwork, track selection, playback controls, progress and server-validated saving.
- Support saved tracks in vanilla jukeboxes, preserving kit identity and NBT when ejected.
- Add KubeJS addMusicKit/changeMusicKit APIs and share the static model renderer with music-kit items.
- Hide music kits with missing client resources and refresh availability after resource reloads.
- Support individual kit ZIPs and a full collection pack without duplicating model geometry or bundling music assets in the mod JAR.
- Reuse eligible static held-case poses and skip empty buffer flushes, with safe fallbacks for animated models and rendering integrations.
- Extend render diagnostics with pose reuse/evaluation and buffer-flush counters.
- Restore patch-envelope animation and correct corrupted Unicode symbols in translations.
- Update the README and KubeJS examples for shared rarities, model items, separate GUI transforms, collection artwork and music assets.
- Allow normal mod builds without the optional music source library.
